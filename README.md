# Vocab-Notes
just a repo for memorizing Vocab

## Running it

Double-click `launch.command` (or the "Launch Vocab-Notes" shortcut on your
Desktop). It sets up the environment on first run, starts the app, and opens
http://127.0.0.1:5000 in your browser. Press Ctrl+C in the Terminal window to stop.

To run it manually:

```bash
python3 -m venv venv        # first time only
source venv/bin/activate
pip install -r requirements.txt
python app.py
```
